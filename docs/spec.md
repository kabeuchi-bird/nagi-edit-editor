CLAUDE.md を基本仕様とし、本書には詳細化・決定事項・keymapper構文の根拠を記録する。
仕様の追加・変更は本書を先に更新してから実装する。

## 2. ゴールデンテストの比較規則

参照元とツール出力を次のように正規化して比較する。

- 比較対象はスロット行（`(` または `#(` で始まる行）のみ。見出しコメント・空行は対象外
- 固有名詞面（`(U I` / `(E R`）の行は対象外（D3）
- 各行を「コメントアウト有無」「トリガー＋キー」「expr」に分解する
  - expr の行末コメントは `#` 以降（ただし `"` を含まない部分）を除去する
  - 空白はすべて除去して比較する（D6, D7）
- スロット行の**並び順**・コメントアウト有無・expr が一致すること
- 例外：D2 の2行は expr を比較しない

## 3. keymapper構文の根拠

出典：https://github.com/houmain/keymapper README（2026-10-24 確認）

| 構文 | 意味 | README の該当節 |
|---|---|---|
| `(A B C) >> X` | 同時押し入力 | Input expressions「`(A B)` means that keys have to be pressed simultaneously」 |
| `^` | 前半は押下時、後半はキーを離したときに出力 | Output on key release |
| `A{B}` | Aを押しながらB | Output expressions |
| `"..."` | 文字入力（Linuxでは日本語文字列が出ないため本ツールでは unsupported 扱い） | Character typing |
| `repeat[EXPR, N]` | 組込みマクロ。EXPR を N 回 | Key aliases / macros |
| `92` 等の数値 | スキャンコード（10進・16進）の直接指定 | Key names |
| `#` | 行末までコメント | Configuration |

運用まわり（docs/manual-test.md の根拠）：

| 事項 | 根拠 |
|---|---|
| 設定ファイルの場所：`$XDG_CONFIG_HOME`・`$HOME/.config`・`/etc`（各 `keymapper/` サブディレクトリ可）、または `-c` 指定 | README「Configuration」 |
| `-u` / `--update` で設定変更時に自動再読込。参照元は `@options no-update` のため自動再読込しない | README「Configuration」「Directives」、参照元設定の冒頭 |
| `--check` で設定のエラーを検査して終了 | `src/client/Settings.cpp` のヘルプ文 |
| 緊急時は Shift+Escape+K で keymapperd を終了 | README「Configuration」 |

- キー名はスキャンコード基準で、ブラウザの `KeyboardEvent.code` に準拠する。英字・数字は `A`〜`Z`・`0`〜`9` の別名あり。`Shift` `Control` `Alt` `Meta` は左右両方に一致する論理キー
- 大文字小文字を区別する

## 4. 出力の構成

面の出力順：`p_l` → `p_r` → `l1` → `r1` → `l2` → `r2`。面と面の間に空行1行。

各面は見出し行（CLAUDE.md 4.2）に続けてスロット行を列優先で並べる。

スロット行：

`(<トリガー> <キー>) >> <expr> # <comment ?? label><接尾辞>`

- status が ok 以外なら行頭に `#`（「未対応・未検証も有効行で出す」がオンなら付けない）
- 接尾辞は status で決まる：unsupported →「（Linux未対応）」、unverified →「（未検証）」、ok → なし。有効行で出す場合も付ける
- 行末空白は削る（expr が空のカスタムアクション対策）
- 「行末コメントを付ける」がオフなら ` # ...` 以降を出さない
- 「固有名詞面を出力する」がオフなら `p_l` `p_r` の見出しとスロット行を出さない
- 出力末尾は改行1つで終える

## 5. 編集状態と Undo/Redo

- Undo/Redo の対象は「レイアウト＋カスタムアクション一覧」の組。出力オプションは対象外
- インポートも1操作として履歴に積む（Undo で読込前に戻せる）

## 6. カスタムアクション

- ID は `custom:` ＋ 一意な英数字
- 「テキスト挿入」：文字列 s から label=s、glyph=先頭1文字、category=text、expr=`^ "s"`、status=unsupported を作る
  - s に `"` を含む場合は作成しない（keymapper の文字列リテラル内でエスケープできるか未確認のため）
- 削除すると、そのアクションを置いていたスロットは空になる
- expr の簡易検証（警告のみ。保存は妨げない）
  - 文字列リテラル `"..."` の外側で `()` `{}` `[]` の対応が取れていない
  - 文字列リテラルが閉じていない
  - 文字列リテラルの外側の大文字始まり識別子が `keys.ts` にない
  - 文字列リテラルの外側に `#` がある（以降がコメントになる）

## 7. 詳細パネル

- 対象は最後にクリック（または Enter/Space）したスロット
- label・glyph・expr・status・comment を編集できる。入力確定（change イベント）で反映する
- 編集対象が「このスロットでしか使っていないカスタムアクション」ならその場で書き換える。それ以外（既定カタログ、または他スロットと共用）は、編集内容でカスタムアクションを複製してこのスロットに置く。カタログ本体は書き換えない
- 「このスロットを既定に戻す」「空にする」ボタン

## 8. パレット

- 既定カタログ＋カスタムアクションをカテゴリ別に表示。label・glyph・expr の部分一致で絞り込み
- パレット→スロットへのドロップで上書き
- クリック入れ替えの選択中にパレットの項目をクリックすると、選択中スロットに上書き（D&Dが使いにくい環境用）
- スロット→パレットへのドロップで空にする

## 9. 既定に戻す

- スロット単位：詳細パネル
- 面単位：各面の見出し横のボタン
- 全体：ヘッダーのボタン。レイアウトのみ既定に戻し、カスタムアクションは残す
- いずれも Undo できる

## 10. 保存と読込

- localStorage キー `nagi-edit:v1:layout` に、状態が変わるたびに CLAUDE.md 7章の JSON 形式で保存
- 読込時の検証（エラーは一覧表示し、読める部分だけで続行）
  - JSON として読めない／オブジェクトでない → 全体エラー、状態は変更しない
  - `formatVersion` が 1 以外 → `migrate` を通す。現状 v1 しかないため 1 以外は全体エラー
  - カスタムアクションの必須項目・型・category・status が不正、ID が `custom:` で始まらない、ID が重複 → そのアクションを捨てる
  - 未知の面ID・キー名、予約スロット、未知のアクションID → そのスロットを空にする
  - `outputOptions` の欠けた項目は既定値で補う
- エクスポートは `nagi-edit-layout.json` としてダウンロード（Blob＋`<a download>`。`file://` でも動く）
