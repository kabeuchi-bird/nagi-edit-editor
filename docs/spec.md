## 2. ゴールデンテストの比較規則

参照元とツール出力を次のように正規化して比較する。

- 比較対象はスロット行（`(` または `#(` で始まる行）のみ。見出しコメント・空行は対象外
- 固有名詞面（`(U I` / `(E R`）の行は対象外（D3）
- 各行を「コメントアウト有無」「トリガー＋キー」「expr」に分解する
  - expr の行末コメントは `#` 以降（ただし `"` を含まない部分）を除去する
  - 空白はすべて除去して比較する（D6, D7）
- スロット行の**並び順**・コメントアウト有無・expr が一致すること
- 例外：D2 の2行は expr を比較しない

## 3. keymapper構文の根拠

出典：https://github.com/houmain/keymapper README（2026-10-24 確認）

| 構文 | 意味 | README の該当節 |
|---|---|---|
| `(A B C) >> X` | 同時押し入力 | Input expressions「`(A B)` means that keys have to be pressed simultaneously」 |
| `^` | 前半は押下時、後半はキーを離したときに出力 | Output on key release |
| `A{B}` | Aを押しながらB | Output expressions |
| `"..."` | 文字入力（Linuxでは日本語文字列が出ないため本ツールでは unsupported 扱い） | Character typing |
| `repeat[EXPR, N]` | 組込みマクロ。EXPR を N 回 | Key aliases / macros |
| `92` 等の数値 | スキャンコード（10進・16進）の直接指定 | Key names |
| `#` | 行末までコメント | Configuration |

- キー名はスキャンコード基準で、ブラウザの `KeyboardEvent.code` に準拠する。英字・数字は `A`〜`Z`・`0`〜`9` の別名あり。`Shift` `Control` `Alt` `Meta` は左右両方に一致する論理キー
- 大文字小文字を区別する

## 4. 出力の構成

面の出力順：`p_l` → `p_r` → `l1` → `r1` → `l2` → `r2`。面と面の間に空行1行。

各面は見出し行（CLAUDE.md 4.2）に続けてスロット行を列優先で並べる。

スロット行：

`(<トリガー> <キー>) >> <expr> # <comment ?? label><接尾辞>`

- status が ok 以外なら行頭に `#`（「未対応・未検証も有効行で出す」がオンなら付けない）
- 接尾辞は status で決まる：unsupported →「（Linux未対応）」、unverified →「（未検証）」、ok → なし。有効行で出す場合も付ける
- 行末空白は削る（expr が空のカスタムアクション対策）
- 「行末コメントを付ける」がオフなら ` # ...` 以降を出さない
- 「固有名詞面を出力する」がオフなら `p_l` `p_r` の見出しとスロット行を出さない
- 出力末尾は改行1つで終える
